# Smuggler: Project Knowledge

## Tech Stack
- **Backend:** Python 3.12+ (uv), Flask, Docker SDK, aria2-rpc. CI tests 3.12/3.13/3.14; the API image ships 3.14.
- **Frontend:** React 19 (Vite), TS, **Mantine** + **Dockview** workbench, TanStack Query, D3. Tailwind was removed — do not reintroduce utility classes.
- **VPN:** WireGuard (raw wg/ip) & OpenVPN (tun0).
- **Storage:** SQLite (WAL), Migration-aware.

## Critical Architectural Rules
1. **VPN-First:** aria2 MUST NOT start until VPN (wg0/tun0) is up and IP verified.
2. **Naming:** Always use "mule", never "worker".
3. **Labels:** Use `smuggler.*` namespace for Docker labels.
4. **No Code Duplication:** API blueprints must call `cli/` clients (docker/aria2).
5. **Security:** Never log or expose PrivateKeys/Credentials. Use environment variables for mule credentials. Every log record passes through the redaction filter in `cli/log.py` (`redact`/`scan_secrets`) and a redaction firing is persisted as a `secret_redacted` event by the observer — treat one as an incident, not noise. Stored OpenVPN passwords **and VPN config bodies** (WireGuard private keys, inline OpenVPN keys) are encrypted at rest via `api/crypto.py` — **scrypt**-derived key from `SMG_SECRET_KEY` + `SMG_SECRET_SALT`, with a `MultiFernet` chain so legacy SHA-256 ciphertext still decrypts and `init_db` rotates it. Strings via `encrypt`/`decrypt`, BLOBs via `encrypt_bytes`/`decrypt_bytes`; keep encrypt/decrypt inside `api/database.py` so callers only ever see plaintext. Writing a secret with no key **raises** rather than silently storing plaintext.
   The API and UI run on Docker bridge networks (never `network_mode: host`), published to loopback only; the API reaches Docker through the **filtered socket proxy** (it does not mount `docker.sock`) and reaches mules over the `internal` `smuggler-rpc` network. `SMG_API_TOKEN` is generated by `setup.sh` and is **required** when `SMG_MULE_RPC_HOST=container`, because mules share that network with the API.
   Mules start from `cap_drop: ALL` and add back only `NET_ADMIN`, `DAC_OVERRIDE`, `SETUID`, `SETGID`, `KILL` (never `SYS_MODULE`), run `no-new-privileges` with memory/PID limits, and drop aria2 to `PUID:PGID` so downloads are not root-owned. The `iptables` kill-switch is **fail-closed**: a mule that cannot pin its endpoint or install a rule aborts instead of running unprotected. The web container runs unprivileged (uid 101).
6. **Path Resolution:** Use `SMG_HOST_ROOT` for paths to be mounted into containers (data/tmp, downloads).

## Core Commands
- **Setup:** `./setup.sh`
- **Prod:** `./start.sh build | stop | prune`
- **Dev:** `./start.sh debug`
- **Test:** `uv run pytest tests/`
- **CLI:** `uv run smg`
- **API deps:** edit `requirements.in` (never `requirements.txt` by hand), then regenerate the hash-pinned lock: `uv pip compile requirements.in -o requirements.txt --generate-hashes --universal --python-version 3.14`. `Dockerfile.api` installs with `--require-hashes --only-binary :all:`, so a stale or hand-edited lock fails the image build.
- **Push:** Following the [Git & Quality Workflow](SKILLS.md#git--quality-workflow)

## Directory Structure
- `api/`: Flask blueprints, database, watchdog logic, observer/events audit engine.
- `cli/`: Shared Docker/aria2 clients, CLI commands.
- `web/`: React frontend (Vite + Mantine) — the only UI. `src/workbench/` is the Dockview panel layout, `src/lib/` the DOM-free logic, `src/test/` the render helper and fixtures.
- `worker_image/`: WireGuard mule Dockerfile/startup.
- `worker_image_ovpn/`: OpenVPN mule Dockerfile/startup.
- `docker/`: API/web Dockerfiles and the nginx template.
- `data/`: SQLite DB, temporary VPN configs (gitignored).
- `tests/`: pytest suite (backend). Frontend tests live beside sources in `web/src`.
- `.github/`: CI workflows (incl. `security-ci.yml`) and Dependabot config.
- `downloads/`: Shared download volume.

## Quality Standards
- **SonarQube:** SonarCloud runs **Automatic Analysis** server-side on push, plus a `sonar.yml` workflow that self-skips without `SONAR_TOKEN`. There is no local scanner — the gate is checked on the PR. Fix all BLOCKERS; a failing gate blocks merge (Project: `ernsoylu_Smuggler`).
- **Testing:** 458 backend tests + 161 frontend tests. Never let a change reduce the count; branding changes must update `tests/`. Frontend tests run as two vitest projects (`vitest.config.ts`): `unit` for `*.test.ts` in node, `components` for `*.test.tsx` in jsdom with Testing Library (`src/test/` holds the render helper, Mantine/jsdom shims and fixtures). Pure logic belongs in `web/src/lib/` so it stays testable without a DOM — prefer moving a decision there over driving a Mantine dropdown in jsdom.
- **Linting:** `lint.select` is pinned in `pyproject.toml` — widening it is a deliberate decision, not something a ruff upgrade should do silently.
- **Typing:** Strict Python type hints and TypeScript interfaces.
